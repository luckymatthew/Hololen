# Hololens 1.2.4：AI 停止、對局記錄及 hBP09 掃描修正

版本 **1.2.4 / versionCode 23**，適用於 Android 15 或以上。延續目前正式版原始碼、原本套件身份及簽署金鑰，可直接覆蓋安裝。以下分開列出已完成的程式修正、實測結果及尚未驗證的範圍。

`hBP06-093` 搜尋完成後，對局記錄遇到 `undefined` 而令 AI 暫停的問題已修正。記錄差異遵循 JSON 的資料語義，準備中的動作不會提前改寫已提交盤面；取消、失敗重試、儲存重開及重播均保留一致的提交邊界。錯誤報告保留可診斷內容，不會以空白記錄或虛構統計代替失敗。

附加對象、手動能力和攻擊候選使用共用合法性判定。`hBP04-105` 的候選不再包含不符合卡文限制的對象，亦不會把被動效果當作可手動啟動的能力。沒有該技能、只能被動觸發、已使用或 Holo Power 不足的推し／SP 技能，也會在模擬前排除；原有 X 費用、特殊減費及相容規則保留。AI 分配生命應援時會評估對手本回合尚未執行的攻擊；真正只有一個合法選擇的提示只驗證一次。搜尋也會保留不同根動作的後續路線，避免大量相似分支過早排除需要多步完成的投資。

Expert 的搜尋上限及模型權重保留。抽樣世界一致的後續計劃，只有在公開盤面、己方已知資訊及規則條件完全相符，並再次通過規則驗證時才可使用；新資訊、條件改變或動作失敗會令計劃失效。此計劃隨提交、取消、儲存及重播一同處理，不依賴未公開的對手手牌或未來抽牌。AI Review 分開記錄真實搜尋、強制選擇及計劃重用，沒有量度的分數或統計不會補造。

掃描已補回 hBP09 全部 **111 張新卡**及其 255 個印刷版本參照：新增 253 份影像特徵，兩個再錄版本沿用既有特徵。原有 2,319 份特徵和順序保持不變，索引合共 2,572 份。這不表示卡庫內每個歷史印刷版本都已有獨立辨識特徵。正式卡圖路徑可正常載入，111 張圖像均成功解碼，薇薇的實際結果畫面及縮圖顯示已驗證。
