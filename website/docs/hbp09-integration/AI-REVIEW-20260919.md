# AI Review v2 integration — 2026-09-19

Offline web and current production Android now export actual AI decision diagnostics as JSON or a four-file ZIP. The signed Android candidate is **1.2.1-ai-review-rc3, versionCode 19**, built from the existing 1.2.0 native project. The stale repository Android preview was not used. Private Android source and signing material are not in this public repository.

The existing native general AI remains in place. Small split-heal choices now enumerate all allocations; selected deck cards stay pinned in sampled worlds; beliefs respect finite card copies and omit diagnostic/private inputs. Koyori hEB01-020/024 reveal counts include assistants when the yellow Oshi skill applies, including reveal deck caps. Existing tests had incorrectly excluded those assistants. See the [official Koyori deck explanation](https://hololive-official-cardgame.com/news_detail/deck-showcase_vol-11/).

Diagnostics record actual generated candidates, selected IDs, targets/payments, measured scores, samples and node attempts. Unmeasured fields are null with reasons. Candidate lists explicitly identify subset coverage. Capture is outside policy state and commits with the game save. The schema-1 match envelope is preserved; a bounded delta history records dropped counts and a reconstruction baseline. Version boundaries are recorded when resuming with a new runtime. Offline exports contain both hands/decks and are never uploaded automatically; PvP private export is rejected.

## Release scope and remaining gates

This is an RC release. Stable 1.2.0 stays available. Missing historical AI source/export-reader binaries prevent exact backward-reader certification, despite schema-1 preservation and legacy reader fixtures. Physical ARM64 phone/camera/fresh Google login, actual disk-full document provider behavior, comprehensive multi-step lethal/strategic-skip oracles and exhaustive cross-set combinations remain unverified. The 38-row evidence checklist records these as partial rather than silently passing them.

Current public code and tests are on PR #2. The private source archive, complete match outcomes, logs, signed APK and install ZIP are supplied in the task workspace. Use `scripts/review-battle.mjs` to reconstruct a retained revision and `scripts/review-battle-zip.py` to safely inspect an export without uploading it. State checksums detect accidental corruption; they are not cryptographic authentication. Source identity hashes cover the documented engine/policy input sets; the private archive includes full per-file SHA-256 provenance.
