# 第五批：昴的同次多目標減傷

日期：2026-09-05

## 修正範圍

hBP04-006 主推技能現在以同一次傷害事件處理：支付一次費用，對該次受傷的全體〈大空スバル〉各減少 30。第一個目標不是昴、後續目標才是昴時，仍會在該次傷害開始前提供選擇；不符合名稱的目標不會得到減傷。略過後，同一事件不會再次提示；獨立事件仍可另行選擇。

固定多目標特殊傷害、原生多目標藝能及 Moona 的中央／聯動特殊傷害加入可序列化的事件識別。藝能附帶特殊傷害與藝能本體使用不同事件，避免減傷延續到下一次傷害。「傷害不可減輕」仍優先適用。

## 官方依據

[hBP04-006 官方卡表及相關 Q&A](https://hololive-official-cardgame.com/cardlist/?id=866&view=text)：Q414、Q416 限定技能發動時的傷害；Q415 說明 Kobo 的後備特殊傷害和後續藝能不能共用減傷；Q428 說明分別造成的藝能與特殊傷害不能合併分配減傷。
