## 實際改動

- hBP01-005 SP 在對手下一個實際回合開始才生效；施放當回合仍可移動對手。施放者的額外回合不會提前消耗持續時間；受影響玩家該回合結束後，限制不延續至其額外回合。
- 限制生效時，重置不把聯動成員退回後排，亦不因退回而休息。只有聯動成員時，中央可以保持空置。
- 接棒與中央／聯動互換遵守限制。通用互換、hBP01-106 和 hSD07-001 不再留下無法完成的選擇；hSD07-001 沒有成員移到後排時不回復。
- 擊倒存檔、存檔成員下層卡、從後排進入空聯動位置仍合法。待決狀態經 JSON 儲存再繼續測試。
