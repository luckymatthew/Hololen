# 第九批：UDIN 抽牌後存檔

日期：2026-09-05。本機修正，尚未發佈。

## 問題與修正

hBP02-097 UDIN 在奧莉 Bloom 時，舊引擎先擷取手牌選項，再抽牌。原本空手時沒有存檔步驟；原本有手牌時不能選擇剛抽到的卡。現在先抽牌再建立手牌選擇，空牌庫仍處理後段存檔。沒有手牌時不產生無法完成的選擇。

## 官方依據

[UDIN 官方卡頁與 Q255](https://hololive-official-cardgame.com/cardlist/?id=364)：藝能 +10；附於奧莉時，Bloom 後抽一張再存檔一張。Q255 明確允許牌庫為零時仍存檔手牌。本輪搜尋工具無法取得該頁，使用直接唯讀 HTTP 成功核實，原始頁保存在 `outputs/udin-official.html`。

## 驗證範圍

`tests/simulator-udin-audit.test.mjs` 共 11 項；第八批引擎 8 過／3 失敗，修正後 11 項全過。涵蓋空手、新抽卡可選、既有手牌可選、必須存檔不可略過、空牌庫、有無附加卡、持有者條件、奧莉配琉依不提供替代選項，以及奧莉／琪亞拉的 +10 藝能。每步行動以 JSON 儲存後續行。

完整回歸 563 項通過，基礎 6,643＋483 案例通過，Windows vinext 建置成功。結果保存於 `batch-09-before.log`、`batch-09-after.log`、`batch-09-regression.log`、`batch-09-build.log`。逐卡 89 卡有局部證據，完整驗證仍為 0 卡。
