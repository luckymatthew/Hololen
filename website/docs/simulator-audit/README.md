## 已完成的驗證

- 6,643 個基礎傷害／特攻／足夠聲援案例通過：使用現有卡片數值、隔離所有技能效果，核對通用結算元件。這不是逐卡效果正確率。
- 483 個真實卡號的無附加文字藝能案例通過：只核對中立對手、足夠費用時的結算。
- 35 個新增邊界測試通過。使用修正前引擎重跑同一批測試，有 16 個失敗；修正後全部通過。費用目錄另有獨立修正。
- 129 個相關回歸測試通過，包含上述 35 個新增測試。
- 基礎數值沿用上一輪有來源的印刷資料校對；本批沒有把「與現有資料相同」當作重新完成官方數值校對。

## 尚未完成／已發現風險

- 全部 1,746 個非空效果欄位，仍需逐一補齊觸發、不觸發、費用不足、合法目標、目標消失、次數限制與結算後狀態證據；本批限定案例不代替完整校對。
- hBP01-005 的一般推し反應效果與可變費用支付，未由本批費用目錄測試驗證。
- hBP03-105 多張附加卡是否能在同一次受傷連續使用，與目前只提供一次反應選擇的流程，待規則核對。
- hBP07-108 的受傷後存檔目前與「受到傷害時」共用前置處理，對手回合及實際傷害大於零的條件仍需修正與測試。
- 特殊傷害的擊倒與受傷觸發順序需獨立核對；目前部分特殊傷害先處理擊倒，可能失去受傷觸發來源。
- hSD13-015、hSD18-004 有上輪保留的效果解讀問題；hBP09-037 缺完整官方效果原文。不能宣稱已驗證。
- 其餘引擎仍有依中文句型辨識效果的路徑，尚未逐卡替換及驗證。
